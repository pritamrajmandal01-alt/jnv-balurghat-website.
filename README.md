# PM SHRI JNV Balurghat — Student Website Concept

A responsive, cinematic single-page website concept for PM SHRI Jawahar Navodaya Vidyalaya, Balurghat. It includes About, Academics, JNV benefits, campus life, facilities, gallery, notices, video showcase, school details and a Google Maps location embed.

## Important publishing note
This is an independent student-created concept, not the official school website. It is not endorsed by the school or Navodaya Vidyalaya Samiti. Demo notices must be replaced with verified school circulars. Stock images are illustrative only; use school-approved photographs or visitor-uploaded photos from the school's Google Maps Photos section only when permitted. No photos have been copied from the CBSE website.

## Preview
Open `index.html` in any modern browser. An internet connection is needed for remote image assets, the Google Maps embed and external links.

## Deploy to Vercel (iPad-friendly)
1. Extract this ZIP on your iPad or computer.
2. Create a GitHub repository named `jnv-balurghat-website`.
3. Upload the contents of the `jnv-balurghat-website` folder to the repository root. Make sure `index.html` is at the root, not inside another nested folder.
4. Open Vercel, choose **Add New → Project**, and import the GitHub repository.
5. Keep Framework Preset as **Other**. Leave Build Command and Output Directory blank (or use `.` as the output directory if Vercel requests one).
6. Select **Deploy**. Vercel will provide the live website URL.

## Editing
- Edit `index.html` to change text, links, images, notices and the video embed.
- Replace demo notice cards with confirmed notices and dates.
- Replace illustrative image URLs with school-approved photographs. The gallery includes a Google Maps link to the school's visitor photo listing.
- The video modal currently uses a sample public YouTube embed. Replace its video ID only with a school-approved video.
